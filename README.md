# تطبيق استخراج وتصميم فتاوى إسلام ويب | Islamweb Fatawa Scraper & Designer

تطبيق سطح مكتب احترافي مبني بلغة **Python** وواجهة **Tkinter الحديثة (CustomTkinter)** مخصص لسحب وأرشفة وإعادة تصميم فتاوى موقع إسلام ويب (العرض الموضوعي) بتنسيق إسلامي طباعي رفيع، وتصدير كل فتوى في مجلد مستقل بصيغ (HTML, PDF, JPEG)، ثم دمج جميع الفتاوى في ملف PDF واحد رئيسي مفهرس تفاعلياً.

---

## 🌟 أبرز مميزات التطبيق

1. **إعادة تصميم صفحات الفتاوى بتنسيق إسلامي متميز (Redesigned Islamic HTML)**:
   - اعتماد خط **مصحف أميري (Amiri Quran)** و **Scheherazade New** لتمييز الآيات القرآنية بأقواس وزخارف إسلامية ذهبية وخلفية سندسية لطيفة.
   - تمييز الأحاديث النبوية الشريفة بخط كلاسيكي وإطار كهرماني واضح.
   - تنسيق أقوال الأئمة والعلماء (ابن باز، ابن عثيمين، النووي، ابن حجر، ابن تيمية...) في بطاقات اقتباس أنيقة.
   - إبراز الصلوات والتعظيمات (صلى الله عليه وسلم، عز وجل، سبحانه وتعالى...) بأسلوب طباعي متقن.
   - خط **Cairo** للعناوين والبطاقات التعريفية والبيانات الوصفية (رقم الفتوى، التاريخ، التصنيف، المشاهدات).
   - تصميم متجاوب تماماً مع الطباعة والشاشات (Print-Ready A4 CSS).

2. **التنظيم الهيكلي للملفات (Organized Storage)**:
   - يتم حفظ كل فتوى داخل مجلد مستقل يحمل رقم الفتوى وعنوانها:
     ```
     fatawa_output/
     └── فتاوى_الإيمان_ونواقضه/
         ├── فتوى_449638_شروط_الدخول_في_الإسلام/
         │   ├── فتوى_449638.html       (الصفحة المصممة)
         │   ├── فتوى_449638.pdf        (ملف PDF طباعي عالي الجودة)
         │   ├── فتوى_449638.jpeg       (صورة مستمرة كاملة مدمجة للصفحات)
         │   └── فتوى_449638_صفحة_1.jpeg
         ├── فتوى_123958_حكم_من_صار_سب_الدين/
         │   ├── فتوى_123958.html
         │   ├── فتوى_123958.pdf
         │   └── فتوى_123958.jpeg
         ├── جميع_فتاوى_الإيمان_ونواقضه_المجمعة.pdf  (الملف الشامل المدمج)
         └── فهرس_الفتاوى.html                        (فهرس تفاعلي محلي)
     ```

3. **الدمج الشامل في ملف PDF واحد مفهرس تفاعلياً (Merged PDF with Bookmarks)**:
   - بعد اكتمال سحب الفتاوى، يقوم التطبيق بإنشاء ملف PDF مجمّع يضم كافة الفتاوى.
   - يتضمن غلافاً أنيقاً وشجرة فهرسة تفاعلية (TOC Bookmarks) في الشريط الجانبي لقارئ PDF، بحيث يمكن النقر على أي عنوان فتوى للانتقال المباشر إليها.
   - توليد ملف `فهرس_الفتاوى.html` كلوحة تحكم محلية بروابط مباشرة لفتح نسخ HTML و PDF و الصور لكل فتوى.

4. **محرك سحب ذكي ومرن (Smart Scraper Engine)**:
   - يدعم روابط التصنيفات الموضوعية (مثل: `https://islamweb.net/ar/fatawa/188/...`).
   - يدعم الترقيم التلقائي للصفحات (Pagination: `pageno=1, 2, ...`).
   - يدعم استخراج الأقسام الفرعية المتفرعة من الموضوع تلقائياً (اختياري).
   - يدعم الروابط المباشرة للفتوى المفردة.
   - حماية من الحظر (معدل زمني آمن بين الطلبات قابل للتعديل).
   - إمكانية تحديد حد أقصى لعدد الفتاوى (أو سحب الكل).

5. **واجهة مستخدم عصرية (Modern Arabic CustomTkinter GUI)**:
   - دعم كامل للوضع الداكن (Dark Mode) والوضع الفاتح (Light Mode).
   - مؤشرات ونسب مئوية حية لتقدم العمل.
   - بطاقات إحصائيات سريعة (عدد الفتاوى المكتشفة، المنجزة، ملفات PDF، الصور).
   - سجل نشاط مباشر ملون (Live Log Console) يعرض كل خطوة بالوقت والنوع.
   - أزرار تحكم كاملة: بدء، إيقاف مؤقت / استئناف، إلغاء نهائي، فتح مجلد الحفظ مباشرة، وفتح ملف PDF المجمّع بنقرة زر واحدة.
   - متعدد المسارات (Multi-Threaded) لضمان عدم تجمد الواجهة أثناء السحب والمعالجة.

## 🚀 طريقة التثبيت والتشغيل

### المتطلبات الأساسية
- Python 3.10 أو أحدث.

### 1. تثبيت الحزم المطلوبة
```bash
pip install -r requirements.txt
```
*(أو تثبيت الحزم يدوياً)*:
```bash
pip install customtkinter requests beautifulsoup4 weasyprint pymupdf Pillow
```

### 2. تشغيل التطبيق
```bash
python main.py
```

## 🛠️ خيارات الاستخدام السريع

1. **سحب تصنيف محدد (مثل الإيمان ونواقضه)**:
   - الصق الرابط:
     `https://islamweb.net/ar/fatawa/188/%D8%A7%D9%84%D8%A5%D9%8A%D9%85%D8%A7%D9%86-%D9%88%D9%86%D9%88%D8%A7%D9%82%D8%B6%D9%87`
   - حدد مجلد الحفظ المطلوب.
   - اختر الفئات المطلوبة للتصدير (HTML, PDF, JPEG, الدمج الشامل).
   - اضغط **🚀 ابدأ الاستخراج والمعالجة**.

2. **التجربة السريعة (تحديد حد أقصى)**:
   - قم بتفعيل خيار "تحديد حد أقصى للعدد" واكتب مثلاً `5` لاختبار سحب أول 5 فتاوى فقط وتوليد ملفاتها ودمجها خلال ثوانٍ.
